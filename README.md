## 📖 About The Project

BuildCore Construction is a modern, fully responsive website designed for a construction company. It features a professional design with a gold and black color scheme, interactive elements, and a seamless user experience across all devices.

This project was developed as part of my web development portfolio to demonstrate skills in building professional, interactive, and responsive websites.

---

## ✨ Key Features

### 🏠 Hero Section
- Full-screen hero with background image
- Call-to-action buttons
- Trust indicators (Years Experience, Projects Delivered, Client Satisfaction)

### 📋 Services
- Interactive service cards
- Residential, Commercial, Renovation, and Project Management services
- "Learn More" modals with detailed information

### 🖼️ Projects Gallery
- Filterable project grid
- Categories: Residential, Commercial, Industrial, Infrastructure
- Project detail modals with features and information

### 💬 Testimonials
- Auto-rotating client testimonials
- Manual navigation controls

### ❓ FAQ
- Expandable accordion-style FAQ
- Common questions about construction services

### 📞 Get a Quote
- Dedicated quote request section
- Comprehensive form with project type, budget, timeline
- Feature highlights (Quick Response, Detailed Estimates, No Obligation)

### 📧 Contact
- Contact information (Phone, Email, Office, Hours)
- Social media links
- Simple contact form for general inquiries
